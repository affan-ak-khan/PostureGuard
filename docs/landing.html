No subscriptions, no cloud, no complexity. Just install, calibrate, and let PostureGuard do the rest.

Run the PostureGuard installer on Windows. No Python knowledge needed — everything is bundled and ready to go in seconds.

Core Features

Everything You Need to
Work Healthier

4
Posture States Detected
30 fps
Real-Time Analysis
3-Level
Smart Alert System
100%
On-Device Privacy
🧍
Posture Detection
Identifies Good, Slouching, Forward Head & Neck Strain posture states using 3D skeletal landmarks via MediaPipe Pose.
👁️
Drowsiness Monitor
Tracks Eye Aspect Ratio (EAR) from 468 face landmarks. Detects tired eyes, slow blinks, and microsleeps in real time.
🔔
Smart Alerts
Three-tier alert system (Gentle → Moderate → Severe) with desktop notifications and Windows SAPI voice alerts. Snooze support included.
📈
Dashboard & Analytics
Interactive Matplotlib charts show posture scores by hour and day. Export session data and track your long-term improvement.
⚙️
Fully Configurable
Five-tab settings dialog lets you tune every threshold, alert volume, camera source, processing confidence, and UI theme.
🌙
Dark & Light Themes
A polished PyQt5 UI built for long sessions, with a toggle between dark (OLED-friendly) and light themes for any environment.
